# Sorting Algorithms Demo

常用排序算法 Python 实现大全。

## 算法列表

### 交换类排序
| 算法 | 时间复杂度 | 空间复杂度 | 稳定性 |
|------|-----------|-----------|--------|
| 冒泡排序 | O(n²) | O(1) | 稳定 |
| 选择排序 | O(n²) | O(1) | 不稳定 |
| 快速排序 | O(n log n) ~ O(n²) | O(log n) | 不稳定 |

### 插入类排序
| 算法 | 时间复杂度 | 空间复杂度 | 稳定性 |
|------|-----------|-----------|--------|
| 插入排序 | O(n²) | O(1) | 稳定 |
| 二分插入排序 | O(n²) | O(1) | 稳定 |
| 希尔排序 | O(n^1.3) ~ O(n²) | O(1) | 不稳定 |

### 归并类排序
| 算法 | 时间复杂度 | 空间复杂度 | 稳定性 |
|------|-----------|-----------|--------|
| 归并排序 | O(n log n) | O(n) | 稳定 |
| TimSort | O(n log n) | O(n) | 稳定 |

### 堆排序
| 算法 | 时间复杂度 | 空间复杂度 | 稳定性 |
|------|-----------|-----------|--------|
| 堆排序 | O(n log n) | O(1) | 不稳定 |

### 非比较排序
| 算法 | 时间复杂度 | 空间复杂度 | 稳定性 |
|------|-----------|-----------|--------|
| 计数排序 | O(n + k) | O(k) | 稳定 |
| 桶排序 | O(n + k) | O(n + k) | 稳定 |
| 基数排序 | O(nk) | O(n + k) | 稳定 |
